# Загадочник

Telegram-бот **логических задач**.

База — **собранные** канонические задачи, не генератор клонов. Книги целиком не копируются.

- Общественное достояние: Дьюдени *Amusements in Mathematics* (1917) — текстовые задачи из глав про меры и переправу (не шахматы и не геометрия с рисунком).
- Я. И. Перельман (†1942): «Живая математика» и арифметические каноны — свой пересказ, не том.
- Е. И. Игнатьев (†1923): «В царстве смекалки» (1908–1915) — текстовые каноны, не книга целиком.
- Фольклор, Алкуин, Тарталья, кружки.
- Смаллиан, Кордемский, Гарднер — только отдельные школьные формулировки, не 70% книги (это уже существенное копирование охраняемого текста).

- фольклор и школьные кружки;
- Я. И. Перельман;
- Б. А. Кордемский, «Математическая смекалка»;
- Дьюдени, Лойд, Кэрролл;
- Смаллиан (рыцари и лжецы) в школьных формулировках;
- классика XX в.: Васон, Монти Холл, Гарднер, Эйлер в учебниках.

У каждой задачи поле «источник». Ответ только по кнопке. Следующая — случайная без повторов до конца круга уровня; затем круг этого уровня начинается заново.

## Запуск бота

```bash
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN='…'   # @BotFather
python bot.py
```

Команды: `/start` `/help` `/stats` `/donate`.
